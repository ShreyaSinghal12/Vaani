Recorded clips go here, one folder per dialect:

    static/audio/malwai/verdict_fake.mp3
    static/audio/malwai/verdict_real.mp3
    static/audio/malwai/verdict_not_sure.mp3
    static/audio/malwai/clicked.mp3
    static/audio/malwai/greeting.mp3
    static/audio/haryanvi/...

When a clip exists, the app plays it instead of text-to-speech. Record the
"say" line from data/replies/<dialect>.json in a quiet room, keep it under
15 seconds, export as mp3.
